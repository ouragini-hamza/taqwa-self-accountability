# تقوى | محاسبة النفس

تطبيق عربي RTL يهدف إلى إيقاظ القلب من الغفلة، وتذكير المسلم بالله، ومساعدته على محاسبة نفسه برفق.

## الوظائف
- مكتبة تذكيرات: آيات مع مراجعها، أحاديث مع التخريج، أسئلة محاسبة وخواطر مميزة بوضوح.
- تذكيرات شخصية: إضافة وتعديل وحذف، مع جدول يومي أو أسبوعي أو مرة واحدة أو فاصل دوري.
- محاسبة يومية قابلة للتخصيص، مع حفظ سجلات الأيام السابقة وملاحظات خاصة.
- أجندة تولّد الأحداث من التاريخ الهجري وأيام الأسبوع، وتشمل الاثنين والخميس والأيام البيض ورمضان والعيدين وعرفة وعاشوراء والجمعة.
- أذكار الصباح والمساء والنوم وبعد الصلاة مع المراجع والعداد.
- إعدادات التقويم، الوضع الداكن، واستيراد/تصدير نسخة JSON.
- حفظ محلي دون تسجيل حساب، وواجهة PWA قابلة للتثبيت.

## التشغيل المحلي
يتطلب Node.js 22 وnpm:
```sh
npm install
npm run dev
``

## الاختبارات والبناء
```sh
npm run typecheck
npm test
npm run build
``

## Android APK
تم إعداد GitHub Actions لبناء نسخة Android Debug باستخدام Capacitor:
1. يبني المشروع ويتحقق من TypeScript والاختبارات.
2. ينشئ مشروع Android بواسطة Capacitor.
3. يبني APK ويرفعه كـ Artifact باسم `taqwa-android-debug-apk`.

بعد نجاح Workflow افتح Actions ثم أحدث تشغيل ثم Artifacts لتنزيل APK.

## ملاحظات مهمة
- التاريخ الهجري حسابي/أم القرى بحسب الإعداد، وقد يختلف عن إعلان رؤية الهلال في تونس؛ المناسبات الموسمية تقديرية.
- إشعارات الويب الدورية لا تعمل بصورة مضمونة إذا أُغلق المتصفح أو أوقف النظام التطبيق. أثناء الاستخدام النشط تُفحص الجداول دورياً، ولا يُدّعى ضمان توقيت الخلفية.
- بيانات المستخدم محلية على الجهاز؛ احفظ نسخة JSON قبل حذف بيانات المتصفح أو إعادة تثبيت التطبيق.
- النصوص القرآنية والأحاديث مرفقة بالمراجع المتاحة داخل التطبيق، وينبغي مراجعتها علمياً قبل النشر العام.
