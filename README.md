# تقوى – محاسبة النفس

تطبيق Android عربي بسيط يهدف إلى تذكير المسلم بالله ومساعدته على محاسبة نفسه يومياً.

## المزايا الأساسية
- تذكيرات إيمانية قابلة للتفعيل وضبط الفترة.
- محاسبة يومية لبنود العبادات والسلوك، مع إمكانية إضافة بنود شخصية.
- أجندة إيمانية مختصرة للأيام والمناسبات المتكررة.
- تخزين محلي على الجهاز دون الحاجة إلى حساب.

## البناء
يتطلب JDK 17 وAndroid SDK. يمكن بناء نسخة Debug باستخدام Gradle:
```bash
gradle assembleDebug
```

ملف APK الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## تنبيه
التذكيرات أدوات مساعدة وليست بديلاً عن التقويم الهجري المحلي أو التحقق من دخول الشهر. الأهداف العددية في التطبيق أهداف شخصية وليست أحكاماً أو سنناً منسوبة بلا دليل.
